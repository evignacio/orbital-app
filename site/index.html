01 · A ideia

Um céu no lugar de dez painéis.

Equipes cuidam de dezenas de sistemas em vários ambientes. Saber quais estão funcionando costuma exigir abrir painéis, ler logs ou esperar alguém reclamar. O Orbital troca isso por um céu: basta olhar para ver qual planeta mudou de cor.

No ar

Respondeu rápido e sem erro. Nada a fazer.

Degradado

Respondeu, mas levou mais de 3 segundos (padrão). Vale ficar de olho.

Fora do ar

Respondeu com erro, não respondeu ou passou de 5 segundos (padrão). Se você estiver em outra aba, o Orbital avisa.

Verificando

Acabou de ser cadastrada. Ganha cor na próxima rodada de verificação.

02 · Funcionalidades

Tudo o que o painel faz.

Cadastre uma vez. Daí em diante, o Orbital verifica, mostra e avisa sozinho.

Visão orbital

Aplicações viram planetas animados. A cor mostra o último resultado.

Três ambientes

Desenvolvimento, homologação e produção, cada um com seu próprio céu.

Tempo real

A cada 30 segundos (intervalo configurável na API) o servidor verifica tudo, e o resultado chega ao painel no mesmo instante.

Verificar agora

O botão “Sincronizar” verifica o ambiente na hora, sem esperar a próxima rodada.

Cadastro simples

Nome, time, ambiente e o endereço que diz se a aplicação está bem (health check). O link da documentação é opcional.

Alerta de queda

Se uma aplicação cai enquanto você está em outra aba, o Orbital avisa com notificação e bipe (você escolhe quais ligar).

Busca e filtros

Ache uma aplicação pelo nome ou pelo time e filtre por status.

Modo tempestade

Se o painel perde contato com o servidor, o céu fecha e mostra o último estado conhecido e a hora da última verificação.

03 · Arquitetura

O servidor verifica. O painel só mostra.

Com dez pessoas olhando o painel, cada aplicação continua recebendo uma única verificação por rodada. O navegador não testa nada: recebe os resultados prontos por uma conexão que fica aberta.

Sem etapa de build no frontend. Cada peça tem um papel claro.

05 · Começar

Coloque seu céu no ar.

Com o Docker instalado, um único comando inicia o painel, a API e os bancos, já com aplicações de exemplo.

Antes de começar

  • Git, para baixar o código
  • Docker com Docker Compose
Ler o README completo
1Baixe o código
$ git clone https://github.com/evignacio/orbital-app.git
$ cd orbital-app
2Inicie o Orbital
$ docker compose -f docker-compose.local.yml up -d --build

Na primeira vez, o banco é preenchido com 10 aplicações de exemplo.

3Abra o painel
http://localhost

Em até 30 segundos os planetas ganham cor.

Outras tarefas

Usar um MongoDB e um Redis que você já tem

O modo produção sobe só o painel e a API. Preencha o arquivo api/.env.prod com os endereços dos seus bancos.

Modo produção
$ cp api/.env.prod.example api/.env.prod
$ docker compose -f docker-compose.prod.yml up -d --build
Rodar os testes da API

Não precisa de MongoDB, Redis nem rede: tudo é simulado. Só o npm install baixa pacotes.

Testes
$ cd api
$ npm install
$ npm test
Parar o Orbital
Parar
$ docker compose -f docker-compose.local.yml down

Para apagar todos os dados, inclusive as aplicações que você cadastrou, acrescente -v ao fim do comando. Isso não pode ser desfeito.
